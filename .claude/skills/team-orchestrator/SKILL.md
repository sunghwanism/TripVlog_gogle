# Team Orchestrator

## When to Use

Use for multi-track work that benefits from parallel agent teams.

## Workflow

1. Break work into independent streams
2. Assign each stream to a team member
3. Define clear input/output expectations
4. Monitor progress and merge results

## Output

- Team assignments
- Status per stream
- Consolidated results
