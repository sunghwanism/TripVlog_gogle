# Prompts Chat

## Goal

Curate, refine, and organize chat prompts for consistent usage.

## Workflow

1. Review existing prompt files
2. Remove duplicates or outdated prompts
3. Add new prompts with clear intent and usage notes
4. Keep naming consistent

## Output

- Updated prompt files
- Summary of changes
