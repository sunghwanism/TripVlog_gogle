# Verify Implementation

## When to Use

Use after coding to confirm requirements are met and no regressions exist.

## Workflow

1. Review requirements/specs
2. Compare code changes to requirements
3. Run relevant tests or checks
4. Report any gaps or risks

## Output

- Verification summary
- Missing items (if any)
- Recommended fixes
