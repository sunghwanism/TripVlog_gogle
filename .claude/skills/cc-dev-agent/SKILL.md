# CC Dev Agent

## Purpose

Provide a general-purpose development workflow for code changes.

## Workflow

1. Read relevant docs and requirements
2. Inspect code to identify change points
3. Implement changes with minimal scope
4. Verify with tests or checks
5. Summarize results and next steps

## Output

- Summary of changes
- Verification status
- Any follow-up needed
