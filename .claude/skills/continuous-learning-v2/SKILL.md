# Continuous Learning v2

## Goal

Capture lessons from completed work and keep project knowledge up to date.

## Workflow

1. Review recent work and diffs
2. Extract reusable insights, patterns, and pitfalls
3. Update relevant docs (rules, guides, checklists)
4. Summarize what changed and why

## Output

- Learning summary
- Doc updates (if needed)
- Next recommendations
