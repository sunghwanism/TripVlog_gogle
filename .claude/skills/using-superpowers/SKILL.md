# Using Superpowers

## Purpose

Explain how to discover and use skills effectively.

## Key Rules

- Use a skill when the task matches its description.
- Read the skill's SKILL.md before acting.
- Prefer minimal context and only required references.
- Announce which skill you are using and why.

## Workflow

1. Identify applicable skill(s)
2. Read the SKILL.md
3. Follow the workflow exactly
4. Report results and next steps
