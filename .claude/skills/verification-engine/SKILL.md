# Verification Engine

## When to Use

Use to validate code changes with build/test/lint pipelines.

## Workflow

1. Detect project type
2. Run the correct verification commands
3. Analyze failures and suggest fixes
4. Re-run to confirm

## Output

- Verification results
- Failures and fixes
- Final status
